## 1. 官方到底明确了什么

`C题.pdf`第1页问题2规定：“除紧急购电费用外，其他时间段的购电费用均按计划购电量计算。”因此按计划量计费与何时付款是两个问题，不能用“没有预付资金”推出“按实际取用量退款”。本题不需要资金余额、保证金或资金流约束。

第2页问题3规定：每天0:00、6:00、12:00、18:00可获得未来24小时整点的光伏预报；0:00制定当天计划，其他预报时刻可以调整；计划高于调整的部分按交易电价50%为违约电价，调整高于计划的部分按1.5倍；总费用包括计划、紧急及调整相关费用。题面没有明确解释取消部分原价是否保留，也没有明确规定中间每个修改版本是否逐笔累计收费。

第2页附录1给定：容量12000 kWh、最大充放电功率5000 kW、2025-01-01 0:00初值6000 kWh、后续1200—10800 kWh及“充放电效率90%”。本项目继承 ηc=ηd=0.9，承认它是对效率文字的工作解释。P3没有重复P1的每日始末相等要求；严禁每天用赋值语句把实际电量重置为6000。

第3页明确：result3计划页保存0:00计划；调整页保存根据其他预报制定的调整购电量；充放页和紧急页保存最终结果。正式输出区间为2025-02-01至12-31，共334天。

## 2. 附件3：已查实的结构，不再重做Common

每个键为 `(issue_datetime, horizon_hour)`；目标整点为 `issue_datetime + horizon_hour`。必须保留发行时刻和目标时刻两个轴，不得仅按目标时刻取“全年最新版本”。

原件有40个名义目标日期进入2026。其中4个目标恰为2026-01-01 00:00，在H-END下仍可对应2025-12-31最后一个实际区间；其余36个整点已超出实际数据结束边界。保留预报，不造2026年真实值，不循环挪回2025年。24小时映射至10分钟时段后，最后一天6/12/18点发行的窗口分别有36/72/108个时段在2026年，合计216条无年度实际标签；不能加入正式2025费用或预报误差统计。

上传的早期 `01_preprocessing.zip` 仍包含当时误判日期28而停止的旧报告，缺少纠正后的预报长表；而后续 `02_recon.zip` 已记录其冻结哈希及1460/35040完整网格。这是快照时点不同，不能据此重开已冻结Common。所附本地脚本读取用户当前正确的 `pv_forecast_hourly_long.csv`，逐值与原件核对。

## 3. 三种时间轴与信息可用边界

继承H-END：交付槽j为 `[d 00:00+(j-1)×10min, d 00:00+j×10min)`，其原marker为右端标记。slot1=0:00—0:10，slot144=23:50—24:00。

| 发行/决策时刻 | 已执行的当日槽 | 当前真实状态 | 可改当日槽 | 当日剩余槽 | 24h窗口中的次日槽 |
|---|---|---|---|---:|---:|
| 0:00 | 无 | 前一日真实S144 | 1—144 | 144 | 0 |
| 6:00 | 1—36 | 真实S36 | 37—144 | 108 | 36 |
| 12:00 | 1—72 | 真实S72 | 73—144 | 72 | 72 |
| 18:00 | 1—108 | 真实S108 | 109—144 | 36 | 108 |

例如6:00决策可以用刚结束的5:50—6:00实际观测，不能用6:00—6:10的最终实际平均值。对“当前槽快速反馈”的旧假设，仍需与0/6/12/18的计划决策分开：反馈发生在槽内；发行时的计划网关不读取尚未结束槽的完整实际量。

预报窗口跨到次日不等于今天可以签订/改写次日全部正式合同；本轮约定只改当日未执行承诺，次日部分至多用于内部前瞻。具体前瞻长度及终端价值由A-4决定，不能未经选择把P2的48h闭合当作P3题设。

当前库存是观测状态。未来库存仅是模型变量，不能读取另一条策略未来的实际SOC，也不能拿0:00名义S36冒充6:00真实S36。

## 4. 小时功率→10分钟能量：明确新假设，不能默认为平均电量

题面用语是“未来24小时整点的光伏发电功率”，没有说“每小时平均功率”。因此不能自动把每个值复制六次后声称官方规定如此，更不能把一个kW值当一小时或一槽的kWh。

**本轮工作映射：`PWL_POINT_TRAPEZOID`。** 把同一次发行的h=1..24值视为整点功率预测，在相邻整点之间线性插值，逐10分钟区间积分；得到区间平均kW和区间kWh两个量，后者进入调度。此映射是作者假设，不是对真实小时内曲线的恢复。

发行时刻h=0没有官方预测点。使用最近已经完成的10分钟实际PV区间代表值作为边界点代理，并保存 `anchor_source_end=issue_datetime`；它不是声称已测得数学意义的瞬时功率。只有2025-01-01 0:00没有任何更早观测时，用同次发行h=1值作为h=0代理，明确标记 `first_issue_forecast_hold`。其他发行时刻若找不到该已完成槽，停止而不读未来补值。

设某小时两端节点为P_h、P_(h+1)，小时内第q槽(q=0..5)的平均功率为 `(1-w)P_h+wP_(h+1)`，其中 `w=(2q+1)/12`，槽电量再乘1/6。六槽能量和等于该小时梯形积分。不能只取右端瞬时功率再当区间平均，却仍称为同一积分口径。

原预报值不改，不从全年actual拟合日出日落掩码，不按未来误差挑映射。`HOUR_END_BLOCK_CONSTANT`仅记录为以后需要时的语义敏感性，不在本轮搜索哪个映射使全年费用最低。OI-06、OI-13保持“已选工作解释、官方语义仍开放”。

P3-1正式算误差时，还必须说明比较的是整点代表误差还是10分钟区间平均误差。已完成观测代理不等于同一时刻瞬时真值；二者不能混为一个指标。

## 5. 结算合同：两项独立歧义，不能混为A/B线路输赢

### 5.1 主工作解释

设某交付槽的0:00计划为g≥0，交付前最后有效的普通购电承诺为a≥0，单价p为附件1对应交付槽单价，紧急购电为e≥0。主解释采用：取消量不再承担全价购电，仅按50%违约计费；中间修改版本全部留痕，但同一交付槽按最终a相对初始g结算一次。

普通及调整费用：

`C_ord = p*min(g,a) + 1.5*p*max(a-g,0) + 0.5*p*max(g-a,0)`

等价于：`C_ord = p*(a + 0.5*abs(a-g))`。

最终账单：`C_total = C_ord + 5*p*e`。

若以0:00报价p*g作基准，则增量为：`1.5*p*max(a-g,0) - 0.5*p*max(g-a,0)`。取消承诺时的负增量是合约回冲，不是售电收入。不得先算p*g，再加一次完整C_ord；不得把取消部分同时算原价和主解释的取消替代费。

选择依据是题面“计划/调整”两种量的措辞，以及可选减购条款在免费处置富余时的经济含义；**不是“这个解释让价格更低，所以选它”**。原文没有唯一消歧，主解释必须在论文假设和结果说明中登记。

### 5.2 关键手算

p=1，g=100：不调整a=100付100；减到80付80+10=90；增到150付100+75=175；取消至0仍付50。若减到80后又紧急买10，则总费90+50=140。若没有正式减购、仍承诺100但只使用80，普通费仍为100，未使用量20，不得自行按90结算。

同一交付槽路径100→150→80，主解释最终普通费为90；路径100→150→100，主解释为100。版本历史仍必须保存，不能因为不按路径收费就删除调整记录。

### 5.3 两个明确登记的备选解释

`NONREFUNDABLE`：初始p*g始终照付，额外加1.5p上调和0.5p下调。例100→80为110。正价、无售电收益且允许免费处置多余供能时，减购一般被不调整支配；这是模型推论，不是官方语义的证明。

`INCREMENTAL_CANCEL_SUBSTITUTION`：每次版本相对上一版，增量记1.5p上调−0.5p下调，初始计p*g；等价于 `p*(a_K+0.5*Σ|a_k-a_(k-1)|)`。路径100→150→80为140；单调100→90→80为90。该式是在固定交付槽价格下明确定义的一种逐次合同，不冒充所有真实市场规则；“每次回退时退还多少历史溢价”原题同样没规定。

本轮只用小例验证三种合同，不跑三套全年策略。后续若需要敏感性，必须分别命名账本，不能在同一结果中混算。

### 5.4 “交易时刻”价格归属

P3虽采用每天相同的电价曲线，但日内价格并非常数。本轮沿用“交付槽p_t”，即对18:00—18:10的调整用该交付槽价，不用做出决定时6:00的价格。该归属是工作合同的一部分；题面未单列调整发行价规则，登记为P3-S03。P4必须重新审视未来电价可知性(OI-12)，不能默认全年价格提前已知。

## 6. result3.xlsx的字段合同

原件有四张表：计划购电量、调整购电量、充放电量、紧急购电量。前两张都是 `A1:EQ335`：A为日期，B:EO为144个十分钟位置，EP“全天购电量”，EQ“全天购电费”。**调整表没有6/12/18三组版本轴，所以不能把三个版本顺序拼进去，也不能相加成日购电量。**

本轮输出工作合同：

| 表/字段 | 保存含义 |
|---|---|
| 计划表B:EO | 0:00原计划g0，不被后续修订覆盖 |
| 计划表EP | Σg0 |
| 计划表EQ | Σp*g0，初始计划报价/基准费用 |
| 调整表B:EO | 各槽交付前最终有效普通承诺a_final；不是带符号的a_final−g0 |
| 无任何调整的槽 | a_final=g0，不能填0表示“没调整” |
| 调整表EP | Σa_final，不含紧急量、不累加版本 |
| 调整表EQ | ΣC_ord+Σ5p*e，最终实际日总账单；属于明确的导出约定 |
| 充放表 | 最终实际C/D四小时汇总、真实0:00/24:00库存 |
| 紧急表 | 最终实际紧急事件，不含已计划的1.5倍正常增购 |

两个EQ不能相加；版本调整费、退订回冲、紧急费应另存费用明细。正文题目表1建议清楚区分原计划和最终普通量，并另报紧急量、总费用，避免一个“购电量”同时指三种不同概念。

原模板B1仍写`0:10-0:20`，EO1写`0:00-0:10+1`。继续采用P2同日位置映射：列j对应H-END物理槽j。保留模板，不静默改表头；用本包 `p3_result3_slot_map.csv` 显式说明物理时间。充放/紧急表的区间标签按真实区间生成，不用模板购电表的歧义标题反推。

充放表原件含样例及省略号，不是只填写这几天；正式导出以后应覆盖334天×6个四小时块=2004条。紧急表同样是动态长度。**本轮不填表、不扩表、不生成result3.xlsx。**

必须另存两个未来的内部账本（本轮只规定字段）：
- 决策版本表：发行时刻、目标日期/槽、是否可修改、g0、旧承诺、新承诺、变化量、真实SOC、所用预报发行、实际信息截止、预计keep/adjust成本及是否采用。

## 7. 本轮对前面讨论的两项校正

“到点更新不等于必须改计划”正确，但若不调整本来就在新优化问题可行域内，且费用已完整包括调整成本，则优化本身已可选不改；keep-versus-adjust比较是可解释的验收，不必额外包装成全新算法。两项预计成本必须用相同新信息、真实SOC、预测风险与终端口径计算。其差只是该模型下的预计调整收益，不能冒充全年实际收益或严格的统计信息价值。

“更多信息时最优值不更差”只在旧策略可嵌入、新信息可忽略、初态和结算一致等条件下成立；不能要求某个近似P3回放必须比P2更低，也不能按全年真实结果临时挑每日赢家。P3-0不设置目标价格、不决定12点最优、不训练门控器。

## 8. P3-1/A-4还要做什么，哪些本轮不做

P3-1可在本合同下构造小时/10分钟匹配表、按发行时刻及提前量分析误差；在线校准时只能用目标区间已结束的历史误差，整条24小时误差路径需全部实现后才能使用。描述性全年图与运行时训练集必须分开。

A-4再决定负荷预测模型、净负荷误差组合、风险分位/不确定集、预报使用组合、调度时域和终端设计。官方新增的是PV预报，不能把P2净负荷分位预测随意加减一个不同口径PV曲线后仍称校准好的分布。鲁棒预算和参数不能从外部论文直接搬过来，题面没有的弃光罚款/资金成本也不新增进正式账单。
