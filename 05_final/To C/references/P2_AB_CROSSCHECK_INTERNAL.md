### 2.2 物理时间轴的建立（以 A 的 H-END 为第一工作口径）

- 每天 144 槽，槽 j 覆盖物理区间 `[(j−1)×10 min, j×10 min)`；槽 1 = 0:00–0:10，槽 144 = 23:50–24:00；144 槽恰好闭合覆盖 0:00–24:00，无缺口、无重叠。

| 终端结构 | S0 = 9265.259272 | S0 = 10800 | 该结构下期初 SOC 差的价值 |
|---|---:|---:|---:|
| 无日闭合、自由终端（A 的参考下界结构） | 12,226,656.68 元 | 12,226,042.07 元 | **614.61 元（方向相反，见下文）** |

结论：该 1,534.740728 kWh 期初 SOC 差的费用价值随终端结构在 **614.60 – 26,573.27 元** 之间，**且方向随结构反转**：

- 自由终端（无闭合）：期初 SOC 越高越便宜（多出的存量是白得能量，期末自由），因此 A 的较低期初 SOC 使 A **吃亏 614.60 元**；
- 带闭合（48h 或逐日）：期初 SOC 越高越**贵**，因为闭合要求把水位回补到原点位，起始水位越高、需要回补的水位越高，被迫多做一次"放电—回充"循环，而每循环 1 kWh 要付约 19% 的往返损失。机制已逐项核对：日闭合下 S0 从 9,265.259272 提高到 10,800 会额外充电 175,174 kWh、额外放电 141,891 kWh，多出的 33,283 kWh 净注能全部损耗在电池里（`Δ(取用) = Δ(C−D) + ΔW`，ΔW = 0），必须以 0.798 元/kWh 补购，正好等于 26,573.27 元。因此 A 的较低期初 SOC 在日闭合口径下**送给 A 26,573.27 元的好处**，在 48h 闭合口径下送 13,175.44 元。

## 5. 预测与计划层差异（只做结构性比较，未重新调参）

### 5.1 A-route

- 预测对象：净负荷 N = L − PV 的**残差** r = N − b。
- 结构性基线 b（事前合同）：h=1 时 b = 当日同星期负载 L_{d−7} 减前一日光伏 PV_{d−1}；h=2（次日）时 b = N_{d−6}。
- ML：LightGBM `objective='quantile'`，α = 0.5 / 0.8 各一个模型，18 个因果特征（负载/光伏 lag1、lag2、lag7；近 7 日均值与标准差；前一日均值/最大值；槽位 sin/cos；星期 sin/cos），expanding window（训练集 `target_date < 拟合日`），每 7 天重训一次（首训第 35 天起），共 48 个拟合日 × 2 分位数 = 96 次既有 fit。
- 基线分支（非 ML）：对同一结构性基线 b 使用过去 28 天残差的经验 0.5/0.8 分位数（`js = [max(7, d−28), d)`，严格历史）。
- 在线因果选择器：只用过去 28 天已发布的账本、只用 `[0, d)` 的真实标签，三项条件同时满足才切到 LIGHTGBM（(1) loss_M ≤ 0.98·loss_B，损失为 0.8 水平上的不对称报童损失；(2) 筛查费用不劣；(3) Q50 MAE ≤ 1.10×基线的 MAE）。334 天中 301 天选择 LightGBM。
- 风险信息：直接取所分支的 **Q80 净负荷**作为风险需求进入 LP，构造上做 `q50 = min(a,z)`、`q80 = max(a,z)` 的单调性修复。
- 计划 LP：48h（288 槽）滚动、零成本充放电、目标 min Σp·g、终端 S288 = S0（closed）、**不要求** S144 = S0；仅前 144 槽的计划购电量被冻结并交付。
- 事前性核验：预测账本 `feature_max_date = d−1`、`issued_at = d 00:00`、选择器只读已发布过去日期的账本；特征函数对 `values[:d]` 显式断言 `len(history) == d`。未发现未来信息泄漏。

### 5.2 B-route（按实现如实描述）

- 预测对象：负载与光伏**分别**预测（周同期/同星期均值、Ridge、随机森林，按倒数误差加权集成，442 维特征），再加一个**净负荷残差的近 28 日 80% 分位安全裕度**（改进版在 0.75–0.85 之间随 SOC 自适应），裕度只沿槽位轴做 ±3 平滑。
- 风险信息：网点预测 + 自适应分位裕度，叠加后作为 LP 的净负荷。
- 计划 LP：**逐日** 144 槽、变量 G/C/D/W/S、目标 min Σp·G + 1e-7·Σ(C+D)、**逐日闭合 S(0) = S(144)**（沿用 P1 的初始 SOC），当日计划购电量全额交付并全额取用。
- 事前性核验：walk-forward 训练集 `range(7, day)`、每 7 天重训，残差用完才入队；未来掩码实验通过（破坏第 330 天起的全部实际值，前 299 天预测/裕度最大变化 3.6e-12）。未发现未来泄漏。

## 6. 实际执行层差异

两条路线**都**采用计划层与执行层分离。本节比较的是"两层是否协调、以及不协调如何影响费用"，而不是"名义 LP 的 C/D 没有实际执行 = B 错误"。

### 6.1 A-route 执行层

- 计划购电量冻结：已核验当日实际 `grid_plan_kwh` 与 48h 计划的前 144 槽逐槽完全一致（计划冻结成立）。
- 实际充放电由当前槽反馈控制器给出（capc/capd 受 SOC 与 5000/6 功率限，a = min(capc, max(−capd, g + v − l))）。
- 取用规则：`grid_used + grid_unused = grid_plan` 精确成立；缺电时先放电、后紧急购电，盈余时先充电、后记未取用/弃电。
- 名义 LP 轨迹的使用情况（与 A 自身计划的对照，非与 B 对照）：

| 指标 | 数值 |
|---|---:|
| 名义充电 / 名义放电 | 6,643,706.8 / 5,590,125.2 kWh |
| 实际充电 / 实际放电 | 6,356,246.6 / 5,149,020.9 kWh |
| 名义净（D−C） | −1,053,581.6 kWh |
| 实际净（D−C） | −1,207,225.7 kWh |
| 名义净与实际净相关系数 | +0.9188 |
| 名义"有动作"槽数 | 23,983 / 48,096（49.9%） |
| 实际"有动作"槽数 | 38,217 / 48,096（79.5%） |
| 名义充电>1 kWh 而实际充电≈0 的槽 | 3,570（严格零判据下 3,581） |
| 名义充电≈0 而实际充电>1 kWh 的槽 | 14,170（严格零判据下 14,352） |

即：A 的执行层**也不逐槽复现**名义 LP 轨迹（实际净充电比名义多 153,644.1 kWh，实际动作槽数是名义的 1.6 倍），但相关系数 +0.9188 说明方向高度一致——A 的名义轨迹是作为参考轨迹被"重解"的，而不是被丢弃的。

### 6.2 B-route 执行层

- 计划购电量全额取用（构造上 `grid_unused ≡ 0`，利用率 100.000%）。
- 实际充放电由独立贪心规则给出：盈余即充、缺口即放，**不读取** LP 的名义 C/D；right_endpoint 交付的 CSV 只保留"实际充电量/实际放电量"，不保留名义轨迹。
- SOC 长期顶格：276/334 天以 10,800 kWh 开始一天，324/334 天在日内的某槽触及上限；槽级 29.79% 处于上限。由于上限是吸收态（盈余无法继续充电只能弃电），B 全年弃电 2,604,166.1 kWh，占计划购电量的 11.993%。

### 6.3 两层的协调性如何影响费用（同口径）

| 项目 | A | B | 差（A−B） |
|---|---:|---:|---:|
| 计划购电量（计费量） | 21,803,694.9 kWh | 21,713,150.8 kWh | +90,544.2 kWh |
| 实际取用计划电（grid_used） | 20,509,432.9 kWh | 21,713,150.8 kWh | **−1,203,717.9 kWh（−5.544%）** |
| 计划量利用率 | 94.064% | 100.000% | — |
| 紧急购电量 | 106,753.0 kWh | 127,460.4 kWh | −20,707.4 kWh（−16.246%） |
| 实际购置电量（取用 + 紧急） | 20,616,185.9 kWh | 21,840,611.1 kWh | **−1,224,425.2 kWh（−5.606%）** |
| 电池热损（0.1C + (1/0.9−1)D） | 1,207,738.1 kWh | 1,297,255.5 kWh | −89,517.4 kWh |
| 期末相对期初的储能释放 | +512.4 kWh | 0.0 kWh | +512.4 kWh |
| 处置总量（未取用 + 弃电） | 2,764,032.8 kWh | 2,604,166.1 kWh | +159,866.7 kWh |

**精确闭合验证（同负载、同光伏，两项均为恒等式，不是估计）：**

- 计费量：`ΔG_plan = Δ(C−D) + ΔW − ΔE + U_A`，逐槽残差最大 6.821e-13 kWh；
  −90,029.9 − 1,134,395.4 + 20,707.4 + 1,294,262.0 = **+90,544.2 kWh**，与直接求和完全一致。
- 实际购置量：`Δ(procurement) = Δ(C−D) + ΔW`，残差 0.1 kWh；
  −90,029.9 − 1,134,395.4 = **−1,224,425.3 kWh**，与实际差 −1,224,425.2 kWh 一致。
- 物理解释：A 的实际取电比 B 少 1.204 GWh，等于 A 少弃 1.134 GWh 光伏 + 少在电池里循环掉 0.090 GWh（少的热损），再加期初到期末额外释放的 0.512 GWh 储能——A 用更少的实际购电服务了同样的负载。
- 同时 A 的**计费量**并不更低（+0.42%），因为 A 承诺了 1,294,262.0 kWh 未取用的计划电（利用率 94.064%）。
- B 的对应形态相反：承诺量全部取用，但取用的电有 1.134 GWh 用于替代被自己弃掉的光伏，并多付出 0.0207 GWh 的紧急购电。

即：两条路线各自都存在"计划层承诺与执行层实际取用不一致"的问题，量级同阶（A 1,294 MWh 未取用；B 1,224 MWh 额外实际购置），只是记账位置不同。**该现象在两边同时存在，不能作为任何单方的独有错误。**

### 7.1 总费用几乎相同、但构成不同：精确解释

计划费差 +131,395.68 元的加法分解（同价量口径）：

- 量效应（21,803,694.9 − 21,713,150.8）× 平均价 ≈ **+55,282.64 元（42.1%）**
- 价效应（0.612309 − 0.608811）× 平均量 ≈ **+76,113.04 元（57.9%）**

计划量差 +90,544.2 kWh 的精确来源（恒等式，§6.3）：A 净充放电少 90,029.9 kWh、弃电少 1,134,395.4 kWh、紧急少 20,707.4 kWh，但未取用计划电多 1,294,262.0 kWh——四项大额对冲后只剩 +90,544.2 kWh。

紧急费差 −156,644.87 元 = 量差 −20,707.4 kWh（−16.2%）+ 价格位置差（A 的紧急槽加权均价 5.87 元/kWh，B 为 6.14 元/kWh，即 A 的紧急购电更多落在相对便宜的槽）。

**结论性表述：** A 与 B 的总费用只差 0.180%，但这是两组方向相反、量级相近的项几乎完全对冲的结果——A 多付 131,395.68 元计划费（其中 57.9% 来自购电价格位置、42.1% 来自略高的购电量），少付 156,644.87 元紧急费（量 −16.2%、价格位置更优）。两边的计费口径完全相同（计划量全额计费、紧急严格 5p、未取用不退款、紧急不抵扣计划），因此这个构成差异是模型/风险/计划/控制结构的差异，不是结算口径差异。

### 7.2 与各自完美预见下界的距离（结构对齐口径）

在同一份 48,096 槽输入、同一电价向量、同一 LP 形式下，按**各自**的终端结构重解完美预见下界：

| 路线 | 自身结构下的完美预见下界 | 实际总费用 | 高出下界 | 相对差 |
|---|---:|---:|---:|---:|
| A（48h 闭合 S288 = S0，S0 = 9,265.259272） | 12,247,279.19 元 | 13,976,723.15 元 | 1,729,443.96 元 | 14.12% |
| B（逐日闭合 S144 = S0，S0 = 10,800） | 12,291,024.77 元 | 14,001,972.34 元 | 1,710,947.57 元 | 13.92% |
| 同上，但两边统一用 S0 = 10,800 | A 12,260,454.63 / B 12,291,024.77 | — | A 高出 1,716,268.52（14.00%） / B 高出 1,710,947.57（13.92%） | 差 0.08 pp |

即：**按各自的完美预见下界衡量，两条路线的实现残余差距基本相当（14.12% vs 13.92%；统一初始 SOC 后 14.00% vs 13.92%，相差 5,320.95 元）**。A 的总费用更低，不等于 A 的算法更接近最优；B 距离自己的下界同样是约 14%。本任务不据此判定优劣。

该下界是放宽参考（无预测误差、无不确定性、无当槽决策约束），不是可实施策略，不用于评价任一路线的可实现质量。

同时注意：这里的两条下界是按各自实际期初 SOC 计算的，而期初 SOC 效应的符号随结构反转（§4.1、§4.2）。把期初 SOC 对齐后，A 的运营性优势在 −1,324.08 至 +25,863.80 元之间——因此"总费用更低"与"距下界更近"这两个指标在本例中都不能单独支撑任一方更优的结论。
