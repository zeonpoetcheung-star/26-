# P2 To C｜Master Writing Handoff

## 1. Final定位

Problem 2 唯一主路线：`A-route / ORIGINAL_MAIN`。

**最终计算与答案的唯一 canonical 来源是 `02_batch_run`。** 后面的 A-5R / A-5C / A-5D1 是定向改进实验，没有替换 MAIN；Candidate、Review、Final 只负责冻结、审查和论文交付。

最终方法链：

> 历史季节基准 + LightGBM 残差分位数预测 + 因果在线分支选择 + Q80 风险需求轨迹 + 48h 连续 LP + 当前槽 actual 的储能反馈 + 5倍紧急购电结算。

## 2. 问题分析主线

P2 与 P1 的核心区别是：负荷与光伏实际值存在预测偏差，0:00 必须在未来 actual 未知时锁定全天计划购电量；实际运行中若计划电、PV和储能仍无法覆盖负荷，缺口按 5 倍价格紧急购电。

因此论文应将 P2 写成两个层次：

1. **0:00 日前层**：基于历史数据做因果概率预测，并通过风险需求 + 48h LP 锁定当天144槽计划购电量；
2. **实际执行层**：计划量不再改变，根据当前槽实际负荷、PV和SOC进行充放电，剩余缺口紧急购电。

不要把附件2当天实际曲线直接放入0:00优化。

## 3. 预测模型

净负荷：`N(d,t)=L(d,t)-PV(d,t)`。

历史基准：`b(d,t)=L(d-7,t)-PV(d-1,t)`。

LightGBM预测残差 `r=N-b` 的 Q50/Q80。特征均为历史滞后、过去窗口统计、前一日汇总和日历周期项；运行时特征最大日期不超过 d-1。

LightGBM自可用日起每7天重拟合一次，共96次fit。`fit_date` 表示拟合发生的日历日（当日0:00），训练标签严格截至 `fit_date-1`，不要把 `fit_date=target_date` 的48个重拟合日误写成泄漏。

在线selector只用过去28天已经发布预测的历史表现决定当天用 BASELINE 还是 LIGHTGBM。正式334天中 LightGBM 被选301天。

## 4. Q80风险分位

无储能单槽近似：

`min_g p g + 5p E[(X-g)+]`

内点一阶条件给出 `P(X<=g)=0.8`。所以 Q80 不是拍脑袋安全系数，而是5倍紧急购电非对称成本对应的风险目标。

但加入跨时段SOC耦合后，不能称“逐槽Q80就是完整随机问题严格最优”。Final只称“Q80风险需求轨迹”。

经验coverage约77.75%，明确写为实际回放值，不写“保证80%可靠性”。

## 5. 48h LP

每天0:00向前规划288槽。前144槽是当天 selected 风险预测，后144槽是次日预测，用于缓解单日末端效应。

核心：
- `min Σ p_k G_k`
- `G_k + D_k = n_hat_k + C_k + W_k`
- `S_k=S_{k-1}+0.9 C_k-D_k/0.9`
- `1200<=S_k<=10800`
- `0<=C_k,D_k<=5000/6`
- `G_k,W_k>=0`
- `S288=S0`

只提交前144槽 `G_plan`，次日重新规划；**不设置 S144=S0**。

`S288=S0` 是作者设计，不是题设要求。

## 6. actual反馈与真实账单

全天计划锁定后，名义LP中的C/D只是规划轨迹，实际储能动作由当前actual和当前SOC决定。不能把“名义C/D没有原样执行”本身写成错误；关键是端到端实际回放和费用是否正确。

真实账单：
- `J_plan = Σ p G_plan`
- `J_emg = Σ 5p E_emg`
- `J_total = J_plan + J_emg`

未使用计划电不退款；它和PV弃电必须分开。

## 11. 时间语义 OI-01

内部统一H-END：slot1=0:00–0:10，slot144=23:50–24:00，`0:00+1`=当天24:00。A/B Crosscheck已证明两路线数值位置一致。

官方模板文字仍存在冲突，所以论文写“本文统一采用区间末标记解释并统一物理时序”，不要写“官方唯一正确解释”。工作簿计划页保留模板原始文字、紧急页采用H-END物理区间，论文中应明确这一标签约定差异（Review M6）。

## 12. 初始SOC与跨日状态

题目只给2025-01-01 0:00 SOC=6000 kWh。之后SOC按实际执行连续递推，不能每天重置6000。

2月1日正式期初SOC=9,265.259272 kWh，来自1月因果warm-up。

A/B crosscheck发现两路线正式期初SOC不同，所以两路线约2.52万元总费差不能作为纯算法优劣。正式论文无需出现“B-route”，一般化说明“初始库存与终端结构会影响跨期费用比较”即可。

## 13. 完全信息参考
