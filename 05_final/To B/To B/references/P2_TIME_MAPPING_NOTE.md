# P2时间映射说明

OI-01仍开放。内部采用H-END，slot1对应0:00–0:10、slot144对应23:50–24:00。

官方模板表头B1为0:10-0:20，EO1为0:00-0:10+1。本输出保留原文字，采用同日位置合同：B←当天slot1，EO←当天slot144，334行分别保存该日0:00的144个计划量。该合同是作者假设，未获官方澄清，不能仅因总和相同宣称时间语义已解决。

EP为全天计划量，EQ仅为计划电费。紧急费为5p×紧急电量，总费另列日汇总和报告。论文指定时段按H-END取slot61/73/85/97/109/121。4h汇总使用真实储能动作；E/F只在每日期块前两行记录0:00/24:00与实际储电量。
