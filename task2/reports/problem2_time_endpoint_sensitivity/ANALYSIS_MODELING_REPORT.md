# 问题二时间节点口径建模报告

## 1. 分析目的

附件的 144 个时刻依次为 `0:10`、`0:20`、……、`0:00+1`，但题面没有明确说明时刻代表十分钟区间的左端点还是右端点。为检验该歧义是否影响结论，在不改变预测、风险分位数、储能参数和求解算法的条件下，分别计算右端点和左端点方案。

现有 `result2_improved.xlsx` 作为左端点敏感性方案保留；新建 `result2_right_endpoint.xlsx` 保存右端点主方案，不覆盖原文件。

## 2. 两种时间解释

### 2.1 右端点主方案

将附件时刻解释为相应区间的结束时刻：

| 附件节点 | 对应区间 |
| --- | --- |
| 0:10 | 0:00--0:10 |
| 0:20 | 0:10--0:20 |
| ... | ... |
| 0:00+1 | 23:50--24:00 |

该口径使 144 个数据点恰好覆盖一个自然日，不需要循环移位；前 24 个数据也恰好对应储能汇总表的 0:00--4:00。

### 2.2 左端点敏感性方案

将附件时刻解释为区间开始时刻。原计算将 `0:00+1` 循环移动到首位，并将其视作当日 0:00--0:10，其余数据依次对应后续十分钟区间。

左端点解释更贴近结果模板的原始表头，但会造成数据行覆盖范围与自然日边界不完全一致，因此仅作为敏感性方案。

## 3. 控制变量

时间口径比较中保持以下条件完全一致：

- 使用同一组严格样本外机器学习集成预测；
- 使用同一组实际负载和光伏数据；
- 使用 0.75--0.85 储电量自适应风险分位数；
- 充电效率和放电效率均为 90%；
- 储电范围为 1200--10800 kWh；
- 最大单时段充放电量为 833.3333 kWh；
- 使用相同的日前线性规划和实际因果调度；
- 使用相同的 2025 年 2 月 1 日初始储电量。

右端点方案通过对原数据、预测、电价和误差裕度同步执行逆循环映射得到。该操作只改变节点与区间的对应关系，不引入未来信息，也不重新选择预测模型。

## 4. 右端点输出口径

右端点工作簿将计划购电表头明确改为自然日区间：

```text
0:00-0:10, 0:10-0:20, ..., 23:50-24:00
```

储能充放电继续按六个自然 4 小时区间汇总，紧急购电时间段按自然日时钟合并。

## 5. 校验方案

1. 检查 334 天和 48096 个计划时段是否全部输出；
2. 检查实际能量平衡和储能状态转移残差；
3. 检查储电量、充放电功率和跨日连续性；
4. 复算工作簿中的购电量、计划费用和紧急购电量；
5. 比较左右端点的总费用、紧急购电量、零紧急购电天数和指定日期结果。
