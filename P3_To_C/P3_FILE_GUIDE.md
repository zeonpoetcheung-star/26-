# P3 File Guide

## data
- `FINAL_KEY_RESULTS.csv`：论文主结果。
- `p3_policy_comparison.csv`：12政策总表。
- `p3_opportunity_comparison.csv`：8更新时间组合。
- `p3_component_ablation.csv`：单因素消融。
- `p3_monthly_cost_summary_MAIN.csv`：MAIN月度趋势。
- `p3_forecast_prefix_summary.csv`：PREFIX vs NO_PREFIX。
- `p3_adjustment_issue_summary.csv`：6/12/18更新执行率。
- `p3_specified_*`：题目要求四日期。
- `result3.xlsx`：最终提交工作簿。

## references
- `P3_MODEL_PLAN.md`：完整模型定义。
- `P3_RUN_REPORT.md`：A-5结果。
- `P3_SETTLEMENT_AND_TIME_NOTE.md`：时间与费用口径。
- `A_REVIEW_REPORT.md`：A独立复核。
- `P3_A_B_CROSSCHECK.md`：仅作交叉验证证据。
- `P3_REVIEW_ERRATUM.md`：写论文时覆盖Crosscheck中的两处旧措辞。

## code
供理解实现；论文无需逐段解释代码，也不要重新运行以产生另一版结果。
