# Problem 1｜To B

本文件夹用于 Problem 1 的最终论文级 Figures 制作。

P1 已完成 A-8 Final，模型、时间口径和核心数值均已冻结。请不要重新建模或重新求解，本阶段只负责基于 Final canonical 数据制作适合论文使用的图。

## 1. 最终技术口径

Final 使用：

- 主模型：连续 LP
- 时间口径：H-END
- `0:10` 对应物理区间 `0:00-0:10`
- `0:00+1` 对应 `23:50-24:00`
- 时间步长：10 min，即 `Δt = 1/6 h`
- 主效率口径：`ηc = ηd = 0.9`
- `S0 = S144 = 6000 kWh`
- SOC 范围：`1200-10800 kWh`
- 不允许售电
- 允许弃光

请特别注意：你自己的 B-route 使用了 H-START 时间口径。B-route 只用于 Crosscheck，最终 Figures 必须使用本文件夹提供的 A Final H-END 数据，不能混入 B-route 的逐时段结果。

## 2. 数据使用原则

请以本文件夹中的 Final 数据为唯一数值来源，例如：

- `p1_schedule_internal.csv`
- `p1_summary.json`
- `p1_storage_4h_summary.csv`
- `p1_specified_purchase_intervals.csv`
- `KEY_RESULTS.csv`

不要从图片中反推数字，也不要重新计算一套结果。

如果包含 `diagnostic` 图，它们只是 A-5 求解阶段用于检查模型是否正常的诊断图。

可以参考其中：

- 哪些变量值得展示；
- 哪些关系值得强调；
- 大致需要表达什么内容。

但不要直接对 diagnostic PNG 做“美化”，建议重新从 canonical 数据绘图。

## 3. 推荐 Figures

P1 最终建议控制在 2 张主图左右。

### Figure 1：全天能源调度与电价

主要展示：

- 负荷
- 光伏
- 外网购电
- 电价

重点表达光伏出力、外网购电和电价之间的时序关系，以及储能调度带来的削高价购电效果。

### Figure 2：储能充放电与 SOC

建议同时展示：

- 充电量
- 放电量
- SOC

可以将充电视为正方向、放电视为负方向，并将 SOC 作为曲线展示。

SOC 的 `1200 kWh` 和 `10800 kWh` 边界可以用克制的参考线标识。

如果版面确实需要，可自行增加一张补充图，但不要为了数量而增加无信息图。

## 4. 视觉风格

可以优先参考你自己 B-route 已经形成的绘图方式和审美习惯，再使用 A Final 数据重画。

目标是：

> 看起来像正常数学建模竞赛或学术论文里的人工制图，而不是一眼可见的模板化 AI 图。

因此建议：

- 配色少而稳定；
- 白底或简洁论文背景；
- 网格线弱化；
- 不使用霓虹色、渐变、阴影、发光效果；
- 不做 dashboard/KPI 卡片式布局；
- 不在所有数据点上标数字；
- 不滥用 marker；
- 不为了“高级感”增加 3D、雷达图、Sankey 等；
- 保留自然留白；
- 图题简洁，详细解释交给论文正文和 caption。

可以自由决定字体、颜色、线型、双轴/上下子图等具体视觉方案。

6. 不得把 B-route 的 H-START 数据混入 Final 图；
7. 优先同时输出可编辑矢量格式（PDF/SVG）和论文排版用 PNG。
