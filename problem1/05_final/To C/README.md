## 4. 两个需要谨慎写的边界

### 时间语义

H-END 与 H-START 都可以构造出内部自洽的解释。

A/B Crosscheck 表明：

- 全天购电量等总量基本不受影响；
- 全天购电费用只变化约 0.1 元；
- 但个别 10 分钟指定时段购电量变化明显，最大相对差约 19.8%。

因此建议写成：

> 本文采用时间标记代表对应 10 min 区间右端点的 H-END 解释。敏感性检验表明，该口径选择对全天经济指标影响很小，但对局部时段计划购电量存在一定影响。

不要写成：

> 官方规定 0:10 就是 0:00-0:10。

### 90% 效率

主模型使用：

`ηc = ηd = 0.9`

同时对：

`ηc = ηd = sqrt(0.9)`

进行了敏感性检验。

论文中应明确说明效率具体如何进入 SOC 方程，不要只写“效率为 90%”。
