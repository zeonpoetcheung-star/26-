# 问题四分析与解题思路总结

## 1. 问题分析

问题四是在问题二和问题三的基础上，将固定日内电价改为随日期和时段变化的实时电价，并重新计算两类策略：

- 问题 4-2：波动电价下重新计算问题二；
- 问题 4-3：波动电价下重新计算问题三。

相比前两问，第四问新增的核心任务是价格预测和价格风险控制。模型不仅要判断需要购买多少电，还要判断在哪些价格时段购电、充电和放电。

## 2. 数据特点

附件 4 包含 365 天、每天 144 个十分钟时段的实时电价，无缺失和负价格。

价格具有明显规律：

- 相邻十分钟价格变化连续；
- 前一周同期价格的相关性约为 0.982；
- 全年平均价格曲线与附件 1 的固定曲线几乎一致；
- 价格主要表现为固定日内形状、每日整体升降和局部扰动。

因此，价格预测不需要直接使用复杂深度学习，可优先采用附件 1 基础曲线、前一周价格、历史同星期均值和结构化回归。

## 3. 关键建模口径

### 3.1 价格信息

主模型假设未来实时价格在制定计划时未知：

- 0:00 制定计划时只能使用历史价格和价格预测；
- 6:00、12:00、18:00 可以使用当天已经发生的实际价格修正剩余预测；
- 附件 4 当天未来实际价格只用于事后费用结算；
- 提前知道未来实际价格的结果只作为 Oracle 理论下界。

### 3.2 时间口径

价格、负载和光伏时刻均按照十分钟区间右端点解释：

- 0:10 对应 0:00--0:10；
- 0:20 对应 0:10--0:20；
- `0:00+1` 对应 23:50--24:00。

模板首列 `0:10-0:20` 使用当天 0:20 数据，末列使用次日 0:10 数据。

### 3.3 费用口径

- 计划购电按对应时段实际价格结算；
- 紧急购电按实际价格的 5 倍结算；
- 问题 4-3 上调部分按实际价格的 1.5 倍结算；
- 下调部分取消后只能收回原价值的 50%，其余作为违约损失。

优化时只能使用预测价格，实际价格不能提前进入决策模型。

## 4. 价格预测方法

比较以下五种方法：

| 方法 | 主要信息 |
| --- | --- |
| 附件 1 固定曲线 | 不考虑每日变化 |
| 前一日预测 | 使用昨天同一时段价格 |
| 前一周预测 | 使用一周前同一时段价格 |
| 结构化岭回归 | 基础曲线、前一日、前一周和同星期均值 |
| 自适应集成 | 根据过去误差组合结构化回归和前一周预测 |

正式方案采用 1 月预验证表现更好的自适应集成。其全年价格预测结果为：

- MAE：0.0433 元每千瓦时；
- RMSE：0.0561 元每千瓦时；
- 日内价格排序相关性：0.9508；
- 高价时段召回率：90.25%。

## 5. 问题 4-2 解题思路

问题 4-2 每天只在 0:00 制定一次全天计划。

具体流程为：

```text
历史负载、光伏和价格
  -> 分别进行无泄漏滚动预测
  -> 计算净负荷和价格预测误差
  -> 从相同历史日期抽取联合误差轨迹
  -> 生成5种负荷、光伏和价格情景
  -> 随机线性规划确定全天计划购电量
  -> 实际储能充放电
  -> 按附件4实际价格结算
```

联合情景使用同一历史日期的净负荷误差和价格误差，避免将高负荷和高价格错误地独立组合。模型加入 CVaR 风险控制，减少极端高价和严重预测误差同时出现时的紧急购电风险。

正式模型采用：

> 因果负载、光伏和价格预测 + 5 条联合误差情景 + 随机线性规划 + CVaR。

## 6. 问题 4-3 解题思路

问题 4-3 在一天内进行四次滚动决策：

```text
0:00 制定初始合同
  -> 6:00 更新负载、光伏和价格预测
  -> 12:00 再次更新
  -> 18:00 更新晚间策略
  -> 实际运行和费用结算
```

每次更新时：

- 已经执行的合同不能修改；
- 当前实际储电量作为新的初始状态；
- 使用附件 3 最新光伏预报；
- 使用当天已经观测到的负载和价格误差修正剩余预测；
- 重新优化尚未执行的合同和储能策略；
- 将上调和下调费用计入优化目标。

模型比较表明，随机 CVaR 虽然能够减少紧急购电，但会增加较多正常合同费用。根据题目优先降低总费用的目标，正式结果采用：

> 因果负载与价格预测 + 附件 3 原始光伏预报 + 0/6/12/18 确定性滚动 MPC。

随机 CVaR 模型作为可靠性优先的风险对照。

## 7. 实际储能控制

每个十分钟时段按照以下规则执行：

- 当前合同电量和光伏足够时，优先给储能充电；
- 储能达到上限后，多余光伏可以弃用；
- 当前供电不足时，优先让储能放电；
- 放电后仍不足时，再按 5 倍价格紧急购电；
- 储电量连续传递到下一时段和下一天。

储电量必须保持在 1200--10800 kWh，单个十分钟时段最大充电量和放电量均为 833.3333 kWh。
