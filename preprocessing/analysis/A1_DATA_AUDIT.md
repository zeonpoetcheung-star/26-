## 5. 可复现的单位与缺失处理约定

1. 孕周：`11w+6 -> 11 + 6/7`，`20w -> 20`；兼容W/w。当前全部记录可按这一规则解析。超过题面“通常10—25周”的记录仍保留并标记。
2. BMI：采用原始值；复算 `体重 / (身高/100)^2` 进行核验，不无理由覆盖。男胎最大绝对差约0.002210；女胎已有BMI最大绝对差约5e-9。
3. 唯一缺失BMI位于女胎序号187（Excel第188行），身高162cm、体重95kg；按上述定义可复算为36.19875019。正式预处理时保留原值为空，并在新列记恢复值和恢复来源。
4. “怀孕次数”有 `≥3` 类别，保留为“3次及以上”，不能声称精确为3。
5. 末次月经字段混合Excel日期序号、文本与空白；检测日期为YYYYMMDD数值。按类型解析，保留原文，无法判断则标记。
6. 不做全样本均值填补、标准化、自动异常值删除或重复批次合并。需要从数据估计的预处理参数，留待模型训练折内拟合。
