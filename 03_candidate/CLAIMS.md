# Problem 2｜Candidate Claims

以下结论可以在 A-7 通过后进入论文/Final：

1. P2 采用严格时间顺序的预测—优化—实际回放框架。
2. LightGBM 用于对强季节基准的净负荷残差进行分位数预测，并由过去已发布预测表现在线决定是否采用。
3. 在共同330天评价期，LightGBM 相比历史基准显著降低 Q50 MAE、RMSE 和 Q80 电价加权损失。
4. MAIN 相比纯历史基准 Q80 策略，实际总费用降低约1.05%。
5. Q80主策略明显优于Q50风险消融，说明5倍紧急购电机制下提高需求风险分位具有实际经济价值。
6. 多轮限定改进实验未进一步降低实际总费用，因此 Candidate 保留原 MAIN。
