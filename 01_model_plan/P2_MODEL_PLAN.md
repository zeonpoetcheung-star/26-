## 2. 单位、时段和信息边界

令日期为 d、日内槽 t=1,…,144，Δt=1/6 h：

$$I_{d,t}=[d+(t-1)\Delta t,\ d+t\Delta t).$$

`slot_id=1`为0:00—0:10，`slot_id=144`为23:50—24:00。状态有145个边界点，不能把144条功率记录当成144个含初值的状态点。

$$N_{d,t}=L_{d,t}-P^{PV}_{d,t}\quad(\mathrm{kW}),\qquad n_{d,t}=N_{d,t}\Delta t\quad(\mathrm{kWh}).$$

预测、标签、MAE/RMSE使用 kW；购电、充放电、弃电、SOC使用 kWh；价格为元/kWh，费用为元。不得对已是 kWh 的量再次乘1/6。

在d日0:00，特征、残差校准和模型选择只能使用截至d−1日的实现值。训练日F可使用标签日期j<F，但每个历史样本j的特征仍必须模拟j日0:00，只用j−1及以前的信息。

三类日期不可混淆：

| 对象 | 截止要求 |
|---|---|
| 历史样本j的特征 | `feature_max_date < j` |
| F日拟合模型的标签 | `train_target_max_date < F` |
| d日模型选择的评分结果 | `score_target_max_date < d`，预测须在当时事前保存 |

当前实测功率仅进入当前槽控制与事后评分，不能回流到当天0:00预测。下一槽及更晚实现值不得进入当前控制。

## 4. 历史基准的 Q50/Q80

对有周滞后数据的日期d，令：

$$\mathcal H_d=\{j:\max(2025\!\text{-}\!01\!\text{-}\!08,d-28)\le j<d\}.$$

$$q^{B}_{\tau,d,t}=b_{d,t}+Q_\tau\{r_{j,t}:j\in\mathcal H_d\},\quad \tau\in\{0.5,0.8\}.$$

使用 `numpy.quantile(method="linear")`。样本不足28天时用真实已有天数；空集只在1月初始化时将残差校准量设为0，并明确记录 `calibration_n_days=0`。不得补造历史残差。

这是正式策略的安全基准，不是“不预测”。

## 5. 机器学习：LightGBM 残差分位数

### 5.1 固定18个特征，沿用一月探针

| 编号 | 特征 |
|---|---|
| 1—6 | `load_lag1, load_lag2, load_lag7, pv_lag1, pv_lag2, pv_lag7` |
| 7—10 | `load_mean7, load_sd7, pv_mean7, pv_sd7`；d−7至d−1同槽，标准差ddof=0 |
| 11—14 | `load_prevday_mean, load_prevday_max, pv_prevday_mean, pv_prevday_max`；仅d−1完整日 |
| 15—16 | `slot_sin, slot_cos`；角度2π(t−1)/144 |
| 17—18 | `dow_sin, dow_cos`；星期一=0，角度2π×weekday/7 |

不再追加特征搜索。最早完整特征/标签目标日为1月8日。保留源日期及列顺序，允许向量化缓存，但缓存不能越过各样本的历史边界。

### 5.2 固定模型 [M1]

分别最小化0.5和0.8分位损失：

$$\hat f_{\tau,F}=\arg\min_{f\in\mathcal F}\sum_{j<F,t}\rho_\tau(r_{j,t}-f(X_{j,t})),\qquad
\rho_\tau(u)=\max\{\tau u,(\tau-1)u\}.$$

实际求解为下列固定配置的梯度提升训练，不声称取得该函数类的理论全局最小值：

```python
LGBMRegressor(
    objective="quantile", alpha=tau,
    n_estimators=160, learning_rate=0.05,
    num_leaves=15, max_depth=4, min_child_samples=30,
    reg_lambda=1.0, subsample=1.0, colsample_bytree=1.0,
    random_state=2026, n_jobs=2,
    deterministic=True, force_col_wise=True, verbosity=-1,
)
```

不调参、不使用GPU、不使用验证期做early stopping、不增加LSTM/Transformer/其他树模型。Q50是条件中位数，不称为条件均值。

### 5.3 训练与发布频率

- 至少有28个完整可训练目标日后启用训练，即首次拟合为**2025-02-05 0:00**，标签使用1月8日至2月4日。
- 之后每7天重新拟合：2月5日＋7k天，至12月31日，共48个拟合日期、**最多96次fit**。
- 采用扩展训练集，始终为1月8日至F−1日；同一周内权重固定，但每天按最新已实现历史构造特征。
- 每天为两条预测分支都保存H1预测。LightGBM尚未首次训练的日期明确标记 `NOT_AVAILABLE`，不伪造预测。
- 保存两个模型的LightGBM文本模型文件、特征列顺序、fit_date、训练标签起止日期、样本数、参数及版本。

原始预测：

$$q^{M,raw}_{\tau,d,t}=b_{d,t}+\hat f_{\tau,F(d)}(X_{d,t}).$$

延续探针的交叉处理：

$$q^M_{50}=\min(q^{M,raw}_{50},q^{M,raw}_{80}),\quad q^M_{80}=\max(q^{M,raw}_{50},q^{M,raw}_{80}).$$

保留raw值与交叉率。排序只消除分位次序错误，不保证覆盖率等于80%。

## 6. 因果在线选择：使用真实历史预测，不用拟合后回看

每天d日0:00，使用最近28个完整日 `d−28,…,d−1` 的**事前预测账本**比较B/M。不得用当天最新模型重新预测这些历史日来打分；那是训练内回看，不是样本外比较。

在两分支尚无连续28个完整预测日时，选择BASELINE。因此最早可能启用ML的日期为**2025-03-05**，不是保证该日一定切换。

主损失：

$$\ell_{m,d}=\frac{1}{144}\sum_t p_t\Delta t\rho_{0.8}(N_{d,t}-q^m_{80,d,t}).$$

无储能费用筛查：

$$g^m_{d,t}=\Delta t\max(q^m_{80,d,t},0),\quad e^m_{d,t}=\max(n_{d,t}-g^m_{d,t},0),$$
$$K_m=\sum_{j=d-28}^{d-1}\sum_t(p_tg^m_{j,t}+5p_te^m_{j,t}).$$

仅在下列条件同时成立时，当天采用ML的整条Q50/Q80曲线：

1. 最近28日平均主损失满足 `loss_M <= 0.98 * loss_B`，保留既定2%改善门槛；基准损失近零（≤1e−12）则保留基准。
2. 同窗口 `screen_cost_M <= screen_cost_B + 1e−6 元`。
3. 同窗口 `MAE50_M <= 1.10 * MAE50_B + 1e−9 kW`。

否则使用BASELINE。一次选择用于当天144个槽，不逐槽事后挑胜者。记录全部判断量、评分日期、采用分支和原因。不保证选择器一定优于始终使用基准，全年回放需实际检验。

一天结束后才将当天真实标签和损失加入评分账本。未被采用的分支也继续保存事前预测，避免“只有被选中的模型有评分”造成选择偏差。

## 7. 次日预测 H2：仅作共同规划延伸

为控制计算量，**不另外训练H2机器学习模型**。在d日0:00，预测目标a=d＋1：

$$b^{(2)}_{d,a,t}=N_{a-7,t}=N_{d-6,t},\qquad r^{(2)}_{j,t}=N_{j,t}-N_{j-7,t}.$$

$$q^{(2)}_{\tau,d,a,t}=b^{(2)}_{d,a,t}+Q_\tau\{r^{(2)}_{j,t}:\max(2025\!\text{-}\!01\!\text{-}\!08,d-28)\le j<d\}.$$

H2校准的实现日也严格小于**decision_date d**，不是小于target_date a即可。所有策略使用相同H2规则；H2不参与H1在线选择。

12月31日可根据截至12月30日的历史生成2026-01-01的H2预测，但不得读取2026年的真实值，也不将该日计入正式成绩。

## 8. 5倍费用与风险分位：用途和限度

对无储能的单时段子问题：

$$\min_{g\ge0}\ p g+5p\,\mathbb E[(X-g)^+].$$

在p>0、连续分布和内部最优条件下：

$$p-5p\Pr(X>g)=0\quad\Rightarrow\quad F_X(g)=0.8.$$

有非负购电边界时还需考虑截断；离散分布应按分位数/次梯度解释。

**不能把这一推导推广成“有储能后逐槽Q80仍是完整问题的严格最优解”。** 本方案将Q80作为由费用机制支持的风险需求轨迹，再进行跨时段经济调度。名义LP目标不直接等于真实随机系统的期望总成本，因此不称为“两阶段随机规划”或“全年随机全局最优”。

Q50只作预先规定的风险消融，风险分位不网格搜索。

## 9. 48小时名义优化

每天0:00构造T=288槽：前144槽为所选H1分位预测，后144槽为共同H2对应分位预测，统一转为kWh：

$$\hat n_k=\Delta t\,q_{\tau,k}.$$

价格为附件1按H-END的144槽序列重复两遍。计划变量为 `G_k,C_k,D_k,W_k`（kWh）和 `S_0,…,S_288`（kWh）：

$$\min J^{nom}=\sum_{k=1}^{288}p_kG_k,$$
$$G_k+D_k=\hat n_k+C_k+W_k,$$
$$S_k=S_{k-1}+\eta_c C_k-D_k/\eta_d,$$
$$1200\le S_k\le10800,\quad 0\le C_k,D_k\le M=5000/6,$$
$$G_k,W_k\ge0,\quad S_0=S^{act}_{d,0},\quad S_{288}=S_0.$$

W为净负荷预测下的名义剩余量，不冒充已知真实PV弃电。实际执行另行分解。

48小时末端闭合是本方案的终端设计，不是官方要求，也不保证消除一切终端效应。**不设置S144=S0。** 只冻结前144槽G作为当天购电合同；次日的假想G不对外提交，明天重新规划。

用稀疏矩阵调用 `scipy.optimize.linprog(method="highs")`。一次1441个变量、576个槽平衡/状态等式，初末状态可在bounds固定。复用稀疏结构，不建立稠密年度矩阵。[M3]

### 9.1 互斥与退化处理

正式采用连续LP，输出必须没有实质同时充放电。若出现，只启用以下已证明保SOC的确定性去循环处理，不另试算法：

$$\rho=\eta_c\eta_d,\quad z=\min(C_k,D_k/\rho),$$
$$C'_k=C_k-z,\quad D'_k=D_k-\rho z,\quad h=(1-\rho)z,$$
$$v=\min(G_k,h),\quad G'_k=G_k-v,\quad W'_k=W_k+(h-v).$$

SOC增量保持不变，平衡仍成立，功率用量不增加，费用不增加，且至少一个充/放电量为0。该证明依赖本名义LP的W无额外上界及非负价格；不向其他模型泛化。保留处理前后日志。若费用变化超过数值容差，应怀疑原解未最优并停止，不把显著改进掩盖成舍入。

## 10. 实际运行：计划电费固定，当前储能平衡用闭式规则

本节是一项明确的反馈控制政策，不声称对未来随机路径最优。名义C/D用于解释计划，不作为实际动作强制照搬；下面规则等价于“短缺先取消充电、再放电；富余先停止放电、再充电”的单槽平衡逻辑。

当前SOC为s，计划电量为g，当前负荷/PV电量为l,v，均kWh：

$$\bar c(s)=\max\{0,\min\{M,(10800-s)/\eta_c\}\},\quad
\bar d(s)=\max\{0,\min\{M,\eta_d(s-1200)\}\}.$$

当前剩余电量 `m=g+v-l`。采用有符号储能动作：

$$a=\operatorname{clip}(m,-\bar d(s),\bar c(s)),\quad
C^{act}=\max(a,0),\quad D^{act}=\max(-a,0).$$

这是充放电互斥的闭式定义，不增加二元变量，也不在每个实际槽调用优化器。

再定义剩余缺口：

$$r=l-v+C^{act}-D^{act}-g,$$
$$E^{emg}=\max(r,0),\quad H=\max(-r,0),$$
$$U^{grid}=\min(g,H),\quad G^{use}=g-U^{grid},\quad W^{PV}=H-U^{grid}.$$

U是已按计划付费但未接收的外网电，W才是光伏弃电。必须验证：

$$G^{use}+E^{emg}+v+D^{act}=l+C^{act}+W^{PV},$$
$$0\le G^{use}\le g,\quad 0\le W^{PV}\le v,\quad E^{emg}\ge0,$$
$$s'=s+\eta_c C^{act}-D^{act}/\eta_d\in[1200,10800].$$

**结算始终为：**

$$J_d^{plan}=\sum_t p_tG^{plan}_{d,t},\quad
J_d^{emg}=\sum_t5p_tE^{emg}_{d,t},\quad
J_d^{total}=J_d^{plan}+J_d^{emg}.$$

未接收的计划电不能退款；紧急量按5p收费，不再叠加1p变成6p。不能把未接收计划电混算成光伏弃电。

政策的代价：优先用当前储能补缺，可能消耗之后更值钱的能量，因此端到端费用必须实测，不能从“当前补缺”推导长期最优。

## 11. January 初始化与跨日连续

- 1月2—7日：H1使用前一天同槽净负荷，Q50=Q80；H2周滞后可用则用周滞后，否则用最近已完成日同槽值；无可用残差时校准量为0。
- 1月8—31日：用第4节基准Q80及第7节H2，运行同一48h LP与当前槽控制。
- 每日真实日终状态传入下一天。2月1日状态由上述31天回放得到，不手填6000。

全年真实状态满足：

$$S^{act}_{d+1,0}=S^{act}_{d,144}.$$

各政策的12月31日末态可能不同，必须报告。费用比较是各整套政策在该评估区间的结算差，末态不同时不冒称“纯预测收益”。

## 13. 完全信息参考：一次全评估期下界，不混入可实施策略

仅在事后评估模块读取2—12月未来实际值，构造48096槽的**全评估期连续LP**，状态全程连续、初值与正式政策相同，实际净负荷替代预测，不设置每日闭环，末态只要求1200—10800。购电均可提前按正常价p安排，不另设紧急变量。

该问题同时放宽未来信息、滚动终端与控制政策限制。最优值记为：

$$J_{PI}^{LB}.$$

它是这些放宽条件下的费用下界，而不是一条可实施策略。理由：任一已回放政策的实际储能轨迹均可嵌入该LP，并令普通购电等于其 `grid_used + emergency`；以p替代5p且不为未接收计划量付费，费用不会增加。因此：

$$J_{PI}^{LB}\le J^{total}_{policy}.$$

不得把“逐日分别重置SOC的完美预测求解费用之和”叫作全年下界。仅在求解器确认optimal后报告下界与相对差；超时所得可行目标不是下界。

实施限额：一次稀疏LP调用，时间上限300秒。若未取得optimal，标记 `ORACLE_NOT_CERTIFIED`，不报告“已证明下界”、不追加算法搜索；它是非阻塞的参考项。严禁该模块的结果流向预测、选择器或正式工作簿。

## 15. 指标、审查和解释边界

预测：Q50的MAE/RMSE/Bias；Q80普通及电价加权分位损失、覆盖率；原始分位交叉率；分支采用日数与切换次数。覆盖率是单侧 `actual <= q80` 的经验比例，不是80%预测区间。按月及总计报告，ML不可用日期不虚构指标。

费用：计划量/费、紧急量/费、总费用、未接收计划量、PV弃电、紧急槽/事件数、四个指定日完整表格、各政策评估首末SOC。不得以RMSE稍低代替最终费用评价。

完整性：标准数据、P1、Common和原模板哈希不变。预测档案和运行配置均可追溯；不只相信脚本自报 `PASS`。

重要研究边界：此前Common已使用全年数据作EDA并影响了模型结构选择，因此本评估不能称为完全未接触过的独立年度测试。本文采用按历史时间推进的因果回放，严格限制每次训练/特征/选择/控制的信息，但这不消除方法开发阶段已看过全年描述统计的影响。不能保证未知下一年的泛化性能。

## 16. 自动验证与停止规则

详见同标识任务单。必须包括：

- 训练/校准/特征/在线选择的日期边界；冻结历史预测不得被新模型覆盖。
- 改变某个时点之后的数据，不改变该时点之前的预测、选择与计划。利用已保存模型做3个截止日的前缀不变性检查，不新增fit。
- 334×144=48096正式槽，365天初始化加正式轨迹连续；ML计划最多96次fit。
