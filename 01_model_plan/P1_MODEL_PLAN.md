## 1. Problem 1 要解决什么

Problem 1 给定：

- 一天内的外网电价；
- 一天内的小区负载功率；
- 一天内的光伏发电预测功率；
- 储能设备参数；

要求每天 0:00 制定完整的计划购电与储能充放电策略，使：

1. 微网供能始终满足负载；
2. 储能状态满足容量与充放电功率限制；
3. 0:00 与 24:00 储电量相同；
4. 购电费用尽可能低。

本问是一个**确定性单日周期调度问题**，不做预测模型，不做滚动优化，不做算法竞赛。

# 2. 时间离散与单位

## 2.1 调度粒度

一天划分为 144 个 10 分钟物理区间：

\[
t=1,\ldots,144.
\]

每个区间长度：

\[
\Delta t=\frac{10}{60}=\frac16\ {\rm h}.
\]

内部物理区间统一定义为：

\[
I_t=[(t-1)\Delta t,\ t\Delta t).
\]

因此：

- \(I_1=[0{:}00,0{:}10)\)；
- \(I_{60}=[9{:}50,10{:}00)\)；
- \(I_{61}=[10{:}00,10{:}10)\)；
- \(I_{144}=[23{:}50,24{:}00)\)。

## 2.2 附件1时间标记的主口径

Common 已确认附件1共有 144 个 marker：

```text
0:10, 0:20, ..., 23:50, 0:00+1
```

Problem 1 内部计算采用 **H-END**：

> 附件中的时间 marker 解释为对应 10 分钟物理区间的右端点。

于是：

```text
附件 marker 0:10   → 物理区间 0:00-0:10
附件 marker 10:10  → 物理区间 10:00-10:10
附件 marker 0:00+1 → 物理区间 23:50-24:00
```

选择这一口径的原因是：

- 144 个数据点恰好完整覆盖 0:00–24:00；
- 与题面明确给出的储能边界 \(S(0{:}00)\) 与 \(S(24{:}00)\) 一致；
- 不需要凭空补造 0:00–0:10 的输入数据。

## 2.3 kW → kWh

附件中的：

- 小区负载：kW；
- 光伏预测功率：kW；

必须先转换为每个 10 分钟区间的电量：

\[
E_t^{L}=L_t\Delta t,
\qquad
E_t^{PV}=P_t^{PV}\Delta t.
\]

即：

\[
E=P\times\frac16.
\]

之后模型中的计划购电量、充电量、放电量、弃光量全部使用 **kWh**。

严禁把 kW 数值直接作为 kWh 使用，也严禁对已经是 kWh 的决策变量再次乘 \(1/6\)。

# 3. 决策变量与状态变量

对每个区间 \(t\) 定义：

\[
G_t\ge0
\]

为外网计划购电量，单位 kWh。

\[
C_t\ge0
\]

为微网母线侧流向储能设备的充电量，单位 kWh。

\[
D_t\ge0
\]

为储能设备向微网母线侧释放的放电量，单位 kWh。

\[
W_t\ge0
\]

为未被负载或储能吸收的光伏弃电量，单位 kWh。

定义：

\[
S_t,\quad t=0,\ldots,144
\]

为各区间边界处储能设备的储电量，单位 kWh。

因此一天共有 145 个 SOC 状态点。

---

# 4. 效率口径

题面写“储能设备的充放电效率为 90%”，但未进一步拆分。

主模型显式采用：

\[
\eta_c=\eta_d=0.9.
\]

其中：

- \(C_t\) 为母线侧向储能输入的能量；
- 真正进入 SOC 的能量为 \(\eta_c C_t\)；
- \(D_t\) 为母线侧得到的放电能量；
- 为向母线提供 \(D_t\)，SOC 需要减少 \(D_t/\eta_d\)。

因此 SOC 递推为：

\[
S_t=S_{t-1}+\eta_c C_t-\frac{D_t}{\eta_d}.
\]

该定义必须在代码、表格与论文中始终一致。

## 4.1 必要口径敏感性

OI-03 属于题面真实歧义，因此仅做**同一模型的一次参数口径敏感性**：

若将“90%”理解为整体往返效率，则取

\[
\eta_c=\eta_d=\sqrt{0.9}.
\]

只比较：

- 全天购电费用；
- 全天购电量；
- 总充电量；
- 总放电量。

该敏感性不是候选模型，不参与主模型选择，也不得覆盖正式 `result1.xlsx`。

# 5. 主模型

## 5.1 目标函数

附件1给出区间电价：

\[
p_t\quad({\rm 元/kWh}).
\]

Problem 1 仅要求降低计划购电费用，因此：

\[
\min \quad
J=\sum_{t=1}^{144}p_tG_t.
\]

不增加：

- 电池退化成本；
- 人工惩罚项；
- 售电收益；
- 未由题面给出的线路成本。

---

## 5.2 每个区间的能量平衡

对任意 \(t\)：

\[
G_t+E_t^{PV}+D_t
=
E_t^{L}+C_t+W_t.
\]

左侧：

- 外网购电；
- 光伏发电；
- 储能放电。

右侧：

- 小区负荷；
- 储能充电；
- 弃光。

使用等式而非模糊的“大于等于”，确保能量守恒。

---

## 5.3 储能状态转移

\[
S_t
=
S_{t-1}
+\eta_cC_t
-\frac{D_t}{\eta_d},
\qquad t=1,\ldots,144.
\]

全部量均为 kWh，量纲闭合。

---

## 5.4 SOC 边界

题面给出：

\[
1200\le S_t\le10800.
\]

Problem 1 主模型进一步按照附录给出的唯一明确初始储电量，固定：

\[
S_0=6000.
\]

结合 Problem 1 的首尾相同要求：

\[
S_{144}=S_0=6000.
\]

这避免把初始 SOC 额外当成一个可自由优化的资源。

---

## 5.5 最大充放电功率

储能最大充放电功率：

\[
P_{\max}=5000\ {\rm kW}.
\]

10 分钟内对应的母线侧最大充放电量：

\[
E_{\max}
=
5000\times\frac16
=
833.333333\ {\rm kWh}.
\]

因此：

\[
0\le C_t\le833.333333,
\]

\[
0\le D_t\le833.333333.
\]

---

## 5.6 光伏弃电

题目没有给出：

- 向外网售电价格；
- 反送电机制；
- 强制全部消纳要求。

因此采用最小假设：

> 不允许通过向外网售电获得收益，但允许在光伏富余且储能无法继续吸收时弃光。

约束：

\[
0\le W_t\le E_t^{PV}.
\]

不设置外网售电变量。

---

## 5.7 外网普通购电

题面没有给出普通计划购电的线路功率上限，因此：

\[
G_t\ge0
\]

且不人为增加上界。

不允许 \(G_t<0\)，避免把负购电量偷偷解释成售电。

# 6. 为什么主模型采用连续 LP，而不是 MILP / PSO / GA

Problem 1 中：

- 目标函数线性；
- 能量平衡线性；
- SOC 递推线性；
- 容量与功率限制均为线性约束；
- 决策变量本质为连续电量。

因此主问题属于标准连续线性规划。

不使用 PSO、GA 等启发式算法。

## 6.1 同时充放电

主模型**不增加充放电互斥二元变量**，保持 LP。

原因：

- 外网电价均为非负；
- 储能有损耗；
- 不存在售电套利；
- 允许弃光；
- 同槽充放电不会提供必要的经济收益。

正式求解后必须检查：

\[
C_t>\varepsilon
\quad\text{且}\quad
D_t>\varepsilon
\]

是否同时出现。

取：

\[
\varepsilon=10^{-6}\ {\rm kWh}.
\]

若不存在明显同时充放电，则直接通过。

若出现实质性的同时充放电，**不重新搜索模型**，只触发预先规定的定点处理：

> 固定主问题最优购电费用，在同一 LP 可行域内最小化 \(\sum_t(C_t+D_t)\)，消除退化循环。

默认不启用 MILP。

# 8. 唯一基准：无储能 sanity check

这不是候选模型，只用于验证主结果。

若完全不使用储能，则：

\[
G_t^{base}
=
\max(E_t^L-E_t^{PV},0),
\]

\[
W_t^{base}
=
\max(E_t^{PV}-E_t^L,0).
\]

基准购电费用：

\[
J_{base}
=
\sum_tp_tG_t^{base}.
\]

正式 LP 必须满足：

\[
J_{LP}\le J_{base}+\varepsilon.
\]

否则视为实现错误或约束错误。

# 9. OI-01：内部时间轴与 result1 模板的最终处理

## 9.1 内部模型

始终使用 H-END：

```text
source 0:10   → 0:00-0:10
source 0:20   → 0:10-0:20
...
source 0:00+1 → 23:50-24:00
```

## 9.2 result1.xlsx 输出层

`result1.xlsx` 的“计划购电量”标签从：

```text
0:10-0:20
...
23:50-0:00+1
0:00+1-0:10+1
```

开始/结束。

由于 P1 明确假设每天的电价和负载相同，并要求每日 SOC 周期闭合，因此下一日策略与本日周期策略相同。

输出时按**模板文字区间的真实物理含义**做循环映射：

```text
模板 0:10-0:20      ← 内部物理区间 0:10-0:20
模板 0:20-0:30      ← 内部物理区间 0:20-0:30
...
模板 23:50-0:00+1   ← 内部物理区间 23:50-24:00
模板 0:00+1-0:10+1 ← 下一重复日 0:00-0:10
                       数值等于本周期 0:00-0:10
```

因此：

- 内部求解始终覆盖真正的 0:00–24:00；
- 模板不改标签；
- 不把第一行错填成 0:00–0:10；
- 不丢失 0:00–0:10 的周期策略；
- 全天总量按内部 144 个物理区间计算，不按模板循环后的显示顺序重新累计。

## 9.3 论文指定时段

例如：

```text
10:00-10:10
```

应使用附件 marker：

```text
10:10
```

对应的内部物理区间结果。

同理处理 12:00-12:10、14:00-14:10 等指定时段。
