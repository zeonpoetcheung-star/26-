# P3 To B Master｜绘图手理解版

## 1. 这一问在解决什么
问题3允许每天0:00、6:00、12:00、18:00获得新的未来24h光伏预报。难点不是“预报越新就一定改计划”，而是调整本身有代价，所以要判断什么时候新信息值得转化成新的普通购电承诺。

## 2. 预测层
负荷以“上一周同槽 W1”为底座。6/12/18 到来时，用当天已经发生的负荷偏差做低维收缩回归修正；次日延续不直接继承当天修正。PV 不另训模型，直接使用附件3当前发行版本。

预测侧最清楚的结果：在共同评价范围内，NO_PREFIX 负荷 MAE/RMSE 约 180.74/251.80 kW，PREFIX 约 167.69/222.07 kW。

## 3. 不确定性与优化
当前预报不是当作绝对真值，而是叠加“历史上同发行时刻、同提前量的成熟负荷/PV残差路径”。每次滚动优化向前看24h，当前日未执行时段可以改承诺，次日部分只用于内部前瞻。

## 4. 为什么有 KEEP
6/12/18 新预报到来时同时评价：
- KEEP：保持当前普通承诺；
- ADJUST：采用新的滚动优化候选。

两者都用相同历史情景和相同真实SOC进行因果回放。只有 ADJUST 的条件评分真正更低才接受。所以 MAIN 的 1002 次机会中只执行了 658 次修改，344 次选择 KEEP。

## 5. 结算
主工作口径：最终普通承诺相对0时初始计划结算。保留部分1倍、调增部分1.5倍、调减取消部分0.5倍；紧急购电5倍。论文必须把这是工作解释写清楚。

## 6. MAIN为什么被选中
12条预登记政策都跑完334天。MAIN总费用最低。PARTIAL、WORST、NO_PREFIX、ZERO_TERMINAL都没有替换MAIN。

## 7. 最值得画的结论
- 机会组合：NONE → MAIN 节省约47.44万元 / 3.34%。
- 单时点中 12时的闭环贡献最大，但18时仍有价值，不能删掉。
- PREFIX 降低负荷预测误差，NO_PREFIX 全年费用比 MAIN 高约8.58万元。
- WORST 把紧急购电量降约80%，但总费用反而高约53.58万元，是很好的“经济性—风险”权衡图。
- PARTIAL 条件评分偶尔更好，但全年账单高约1.09万元，说明条件评分改善不等于真实闭环收益。

绘图时不要用 A/B 路线总费用比较作为主图；B-route 与A存在方法、初态和结算差异，Review 明确不把它当等价 benchmark。
